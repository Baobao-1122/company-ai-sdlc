# SDLC 阶段 3：编码实现

## AI 引导职责

收到「开始实现」后**第一句**：

```markdown
✅ 已收到「开始实现」→ 进入 **阶段 3 · 编码实现**

**接下来自动完成（无需你回复）：** 在已声明文件内改代码 → 若改 schema，按 CP-02 计划执行 migration 链 → 若命中业务数据影响面，按计划做**只读**抽样对账并整理结论与问题（禁止改删业务数据）→ 跑 test:harness:ci → 若命中 P1，须 **`🔄 Reflection · P1`**（见 `sdlc-verify` / `docs/code-review.md` §10–§11）
**预计下次需要你介入：** 验证与 Reflection 完成后 **CP-05**
```

- 数据库变更链每一步仅在上一步成功后执行；任一步失败时停止后续步骤（包括 harness），进入 CP-05 汇报并推荐 **Stop**
- 业务数据对账必须只读；校验后只输出结论与问题；不得以对账名义写库；需修数时另开任务并单独授权
- 命中数据影响面时：只读对账须在 `test:harness:ci` **之前**完成；**未执行、缺证据、或核对中写库**时禁止跑 harness，进入 CP-05 推荐 **Stop**；结论为「有差异」但已给出问题清单时仍可跑 harness，由 CP-05 决定是否允许提交
- 进行中：`📍 阶段 3/5 · 编码实现`
- CP-03/04：必须用 **决策包**（业务项目 `docs/qa/ai-sdlc-decision-rubrics.md` §3 CP-03/04）+ 编号选项
