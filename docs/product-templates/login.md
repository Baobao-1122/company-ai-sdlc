# 产品模版：登录与账号

沿用本模版时，下面的能力和交互写入对齐表的「沿用」，不重新设计。本系统只填文末的差异表。

密码怎么存、会话用什么技术，不在本模版里规定。那是设计阶段按本系统技术栈做的技术方案。

## 沿用的能力

| 能力 | 行为 |
|------|------|
| 未登录 | 只能看到登录页。业务页面和业务读取接口需要有效会话 |
| 登录 | 用户名和密码 |
| 错误提示 | 用户名不存在和密码错误使用同一句：「账号或密码错误」 |
| 停用 | 提示「账号已停用」。该账号已有会话同时失效，之后不能登录 |
| 退出 | 可以主动退出。会话有时长，具体时长在差异表填写 |
| 账号管理 | 先看到账号列表。新增、重置密码、修改自己的密码、启用和停用分开做 |
| 删除 | 不提供删除账号 |
| 最后一个管理员 | 不能停用最后一个仍启用、并且能管理账号的管理员 |

## 沿用的交互

1. 未登录访问业务页时进入登录页。登录成功后进入差异表指定的首页。
2. 功能导航只放业务功能。设置进入账号管理。当前用户名打开个人信息，退出放在个人信息里。
3. 账号管理首页是列表，并有新增。选定一项后再进入对应步骤，完成后回到列表。
4. 停用和启用先进入确认步骤再执行。碰到最后一个不能停用的管理员时，说明原因，不执行。

和上面不一致的界面，写进差异表的「界面差异」。没有就写「无」。
