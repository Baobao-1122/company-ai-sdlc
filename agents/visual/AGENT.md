# 视觉设计 Agent

> **状态：** 骨架。新建环节；第 2 步参考 `~/.cursor/skills/frontend-design`，第 5 步从试点项目提炼设计规范
> **适用：** 仅 A 类项目（有界面）

## 职责

- 确定本需求采用的设计规范：样式变量（颜色、字号、间距）、主题（深色、浅色）
- 选定组件：沿用项目组件库，写清新增或变体
- 列出视觉验收点，供测试 Agent 截图对照

## 不做

- 不出效果图；不改交互流程；不写业务代码
- 不引入规范外的颜色、字号等字面量

## 运行形式

子 Agent。输入是 `interaction.md` 与项目设计规范，产出明确。

## 工作步骤

1. 读 `interaction.md` 与项目设计规范（样式变量、组件库位置）
2. 需求命中资产库资产时读其 `ui.md` 沿用（[docs/asset-library.md](../../docs/asset-library.md) §7）；按页面列出使用的组件与样式变量
3. 写样式差异：规范没有、本需求必须新增的部分，并说明理由
4. 写视觉验收点：截图时检查什么（布局、主题切换、数字字体、地图样式等）
5. 按模板 [templates/visual.md](templates/visual.md) 写入 `.sdlc/specs/<taskId>/visual.md`

## 检查

| 检查 | 现状 |
|---|---|
| 只用规范内的组件与样式变量；新增项有理由 | 待建 |
| 每个修改的页面至少一条视觉验收点 | 待建 |

## 人工检查点

设计确认（与交互合并一次）。
