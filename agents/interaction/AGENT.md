# 交互设计 Agent

> **状态：** 骨架。新建环节，无旧 Skill 可迁；第 5 步从试点项目提炼资产
> **适用：** 仅 A 类项目（有界面）

## 职责

- 列出涉及的页面，画页面流程（Mermaid）
- 为每个页面列出状态：正常、空、加载、错误、无权限，以及业务特有状态
- 写关键交互：筛选、排序、分页、导出、弹窗等
- 把每条验收标准对应到页面或状态

## 不做

- 不定颜色、字号、组件样式（视觉 Agent 负责）
- 不做技术方案、不写代码

## 运行形式

主对话出方案（需要和人讨论）；完成后另开只读子 Agent 检查遗漏状态。

## 工作步骤

1. 读 `requirements.md`，列页面清单
2. 查资产库（`assets/README.md`，见 [docs/asset-library.md](../../docs/asset-library.md) §7），命中则读该资产的 `flow.md` 沿用，只写差异
3. 画页面流程，写每页状态表
4. 写验收标准到页面、状态的对应表
5. 按模板 [templates/interaction.md](templates/interaction.md) 写入 `.sdlc/specs/<taskId>/interaction.md`
6. 子 Agent 检查：每条验收标准有对应；每页至少有空、加载、错误、无权限四种状态的处理

“后台列表表格”“地图轨迹回放”“数据大屏”等界面类做法属于资产，不写在本能力包；候选见 [docs/asset-library.md](../../docs/asset-library.md) §8.2。
