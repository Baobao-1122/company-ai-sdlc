# 研发 Agent · 交接约定

## 读入

| 文件 | 用途 |
|---|---|
| `tasks.md` | 任务、改动文件、验证命令（标准档、重型档） |
| `architecture.md` | 方案与条件设计块（标准档、重型档） |
| `route.md` 的“快速档说明” | 快速档的改动、文件、验收标准、验证命令，替代上两项 |
| `interaction.md`、`visual.md` | 页面、状态、组件（A 类项目，路线经过时） |

## 产出

| 产出 | 说明 |
|---|---|
| 代码与 migration | 只限 `tasks.md`（快速档为“快速档说明”）声明的文件 |
| 文档同步 | 按 `docs-sync` 规则 |
| `.sdlc/task-state.yaml` 进度 | 每项任务完成后更新 |

本 Agent 不产出交接文件模板。

## 完成标准

- `tasks.md`（快速档为“快速档说明”）中的验证命令已跑过并记录结果
- 改 schema 时 migration 链四步已完成，或已在 CP-05 标为阻塞
- 无范围外改动；如有，已经 CP-04 确认
